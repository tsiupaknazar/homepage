# 🐶 Patron Resume Project

A funny and creative résumé website dedicated to Patron — Ukraine’s legendary mine detection dog and professional good boy.

This project recreates a modern developer-style CV with a humorous twist, featuring:
- Professional résumé sections
- Career timeline
- Skills and achievements
- Responsive layout
- Funny corporate-style descriptions

## ✨ Features

- Clean résumé-style UI
- Animated career timeline
- Funny “corporate dog” experience descriptions
- Fully customizable HTML/CSS structure
- Beginner-friendly project structure

## 🛠 Technologies Used

- HTML5
- CSS3
